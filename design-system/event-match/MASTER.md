# Event Match — дизайн-система

Направление: спокойный сервис подбора для личных и деловых событий. Пастельные поверхности, тёплый фон, тёмная типографика, понятные действия. Основано на UI/UX Pro Max; яркая маркетинговая палитра из поиска адаптирована под запрос на пастельный продуктовый интерфейс.

## Компоновка

- Десктоп от 1200: боковая навигация 228, основная область с ограничением ширины, 2–3 колонки карточек по доступному пространству.
- Телефон и планшет: верхняя шапка, одна или две колонки. При увеличении текста — одна колонка.
- Фильтры события: правая модальная панель на широком экране, полноэкранная форма до 700.
- Основное действие: «Подобрать под событие». Поиск и категории служат просмотру каталога; подбор по заказу выполняется отдельно.
- Все ссылки и кнопки ведут к работающим действиям. Нет фиктивных рейтингов, фотографий, отзывов и бронирования.

## Компоненты

BrandMark, CatalogHero, ContractorCard и OrderFilters — отдельные компоненты. У карточек общий ритм: категория/город → имя → цена → параметры → описание/объяснение → раскрываемые подробности → источник данных.

Шаг отступов 4/8; основные промежутки 16/20/24/32. Скругления 12–16 для контролов, 24–28 для больших поверхностей. Иконки Material Outlined. Шрифт Roboto с системным fallback, без обязательной загрузки внешних шрифтов. Базовый текст 14–16, заголовки 22–42.

## Проверка и развитие

Тестировать 375, 768, 812, 1024 и 1440 пикселей, увеличенный текст, reduced motion, применение/отмену/сброс фильтров и пустой поиск. Кнопки доступны с клавиатуры, формы имеют подписи; информация не передаётся одним цветом. Тёмная тема пока не реализована.

Локальные превью Flutter (Windows): `flutter test test/design_preview_test.dart --dart-define=VISUAL_PREVIEW=true`. PNG появятся в `build/previews/`. Для снимков используются установленные шрифты Windows; их файлы не включаются в продукт. Это визуальная проверка компонентов, не замена проверке на физическом телефоне.
