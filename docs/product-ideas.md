# Идеи развития Event Match

## Закрытая коммуникационная платформа

Зафиксировано 23.09.2026 по предложению владельца продукта.

**Статус: идея для дальнейшего развития, не текущая задача реализации.**

Направление: развивать Event Match в закрытую коммуникационную платформу, где заказчик после подбора может написать подрядчику прямо внутри приложения. Подбор становится началом общения, а не конечным действием.

Предлагаемый сценарий для обсуждения:

1. Заказчик получает рекомендации и открывает карточку подрядчика.
2. Нажимает «Написать подрядчику» и начинает внутренний диалог.
3. Заказчик и подрядчик обсуждают условия мероприятия в приложении.

До реализации нужно определить:

- Что означает «закрытая»: доступ по приглашениям, проверенные участники или другой вариант.
- Как реальные подрядчики регистрируются и подтверждают свои профили. Текущий датасет анонимизирован и не содержит готовых аккаунтов для переписки.
- Роли, права доступа к диалогам, правила хранения сообщений, жалобы и блокировки.
- Передаются ли условия заказа в чат; состав передаваемых данных подтверждает заказчик.

Сообщения, кабинеты, уведомления, бронирование и оплата сейчас не реализуются. Переписка выходит за рамки исходного хакатонного ТЗ, где требуется только рекомендация; её следует оформлять отдельным продуктовым этапом.
