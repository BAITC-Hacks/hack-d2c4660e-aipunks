# Firebase — архив настройки

Ранее в проекте hackalem-84547 зарегистрированы Web и Android приложения, их публичные настройки сохранены в lib/firebase_options.dart. Платный тариф агент не подключал, Firebase Functions не разворачивал.

**Текущее приложение не инициализирует Firebase и не требует Blaze.** Подбор работает локально; каталог и кэш обслуживает Node.js + SQLite, GPT вызывается сервером.

Действующая инструкция: [локальный сервер и GPT](local-backend.md). Старые настройки не удалены из Firebase Console.
