# Итог подбора и сравнение

Изменения относятся только к представлению результата. Ранжирование, состав
выдачи, GPT-промпты и тексты объяснений не изменяются.

## Сценарий

- После полного подбора сначала показан заголовок «3 лучших кандидата под ваши
  условия». «Лучшие» — порядок, полученный от существующего сервиса подбора.
- При одном или двух вариантах заголовок показывает фактическое число;
  причины исключений остаются видимыми. Отсутствие категории и отсутствие
  проходящих по условиям кандидатов — разные состояния.
- Неполные условия помечаются как предварительная подборка; непроверенные
  параметры не скрываются.
- Статистика «подходят N из M» находится в закрытом по умолчанию разделе
  «Как мы подобрали». Исходная сводка остаётся там без изменений.
- Карточки уже являются сравнением: имя/категория/город → цена «от» → часы →
  языки → форматы → существующее объяснение → происхождение данных → действия.
  На широком экране строки соседних карточек выровнены по фактической высоте.
- Отдельной кнопки «Сравнить» и дополнительного окна сравнения нет. Профиль
  открывается в прежней правой панели, избранное и сообщения сохраняются.

## Помощник

На основной странице помощник закреплён справа. При ширине от 1440 px и обычном
масштабе текста панель занимает 416 px; результат автоматически обновляется слева.
На узком экране панель занимает всю ширину, закрытие возвращает к готовой
подборке. Переписка сохраняется; Escape закрывает панель при фокусе внутри неё.
Скрытая основная страница исключена из клавиатурного обхода.

Публикация результата из чата не вызывает обычный RecommendationService и не
перезапрашивает GPT. Передаются выбранные IDs, исходный порядок и существующие
объяснения. Ручная смена фильтров запускает обычный подбор; подтверждённые дата
и бюджет из чата предварительно заполняют форму. История чата не сбрасывается.

## Границы параллельной работы над объяснениями

- `RecommendationComparison` принимает готовые `Recommendation` и использует
  их `explanation`/`source` без преобразования.
- `AssistantRecommendations` передаёт готовые объяснения из ответа помощника.
- `SelectionPresentation` меняет только заголовок и отображение общей сводки,
  не тексты карточек и не сохранённую историю запросов к модели.
- Пока сервисы возвращают статистику строкой, UI удаляет из основной подачи
  только известный префикс со счётчиками. Полная строка сохранена в раскрытии.
  При изменении формата сводки нужно согласовать этот адаптер либо добавить
  структурированные причины отдельным изменением контракта.
- `max_hours: null` подписан как отсутствие привязки к часам присутствия,
  а не как неограниченная длительность.

## Проверки без сборки и платных запросов

Из `apps/event_match`:

```powershell
flutter analyze --no-pub
flutter test --no-pub
flutter test --no-pub test/selection_handoff_test.dart --dart-define=VISUAL_PREVIEW=true
```

Тесты `selection_comparison_test.dart` и `selection_handoff_test.dart` проверяют
исходы, скрытие счётчиков, выравнивание строк, переносы и крупный шрифт,
публикацию результата без нового ранжирования, сохранение объяснений,
состояние чата и перенос условий в обычную форму. Последняя команда создаёт
локальные PNG в `build/previews/selection-chat-*.png` на подставном сервисе.
Web/APK-сборки и обращения к OpenAI для этих проверок не нужны.
